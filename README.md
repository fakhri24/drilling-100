# Drilling-100

Latihan drilling 100 soal per kompetensi kecil untuk semua materi numerasi kelas X.

**Live**: https://fakhri24.github.io/drilling-100/

## Fitur

- 12 materi, ~50 kompetensi kecil, 5000+ soal
- Pola soal berulang + angka random (range 1-50)
- Jawaban essai singkat (input angka)
- Feedback langsung otomatis setelah jawab
- Progres tersimpan per siswa (Firebase)
- Login via Google atau Email
- Mobile-friendly

## Materi

1. Operasi Aritmatika Dasar
2. Sifat Operasi Bilangan
3. KPK dan FPB
4. Operasi Pecahan
5. Operasi dan Konversi Desimal
6. Pengenalan Variabel
7. Manipulasi Aljabar Dasar
8. Persamaan Linear Satu Variabel (PLSV)
9. Sistem Persamaan Linear Dua Variabel (SPLDV)
10. Persentase
11. Perbandingan dan Skala
12. Pembulatan dan Estimasi

## Tech Stack

- Vanilla HTML + CSS + JS
- Firebase (Auth + Firestore)
- GitHub Pages
